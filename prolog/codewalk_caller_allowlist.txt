# codewalk_caller_allowlist.txt — ADJUDICATED bound call sites on `latent-B` registry rows.
#
# The guard is python/codewalk_caller_check.py (gate row `codewalk caller`), the CALL-SITE
# arm of the bound-dispatch registry: library(prolog_codewalk) over the loaded program,
# module-resolved. A `latent-B` entry in python/dispatch_head_check.py's DECLARED asserts
# "shape present, NO live bound caller". When this arm finds one, that assertion is wrong,
# and the row lands here with its adjudication or the gate goes RED.
#
# WHY AN ALLOWLIST AND NOT A STANDING RED (operator ruling, 2026-08-18). A knowingly-red row
# trains its readers to ignore the channel — the failure this project keeps naming. An
# unwired checker is worse: the finding lives only in an audit dir and the instrument's
# discrimination is unavailable to catch the NEXT one. Same shape as
# prolog/load_warning_allowlist.txt and prolog/axis_boundary_allowlist.txt.
#
# GRAMMAR (checked; a malformed row is RED, never a skipped line):
#     <deffile.pl>:<name>/<arity>  ATOMS=<a1[,a2...]>  REMOVE=<condition>  <reason>
# All four columns REQUIRED. In particular:
#   ATOMS  — the bound atoms adjudicated benign. A bound caller on an allowlisted predicate
#            using ANY OTHER atom is RED. This is not pedantry: over-permissiveness is
#            ATOM-SPECIFIC (see the signature_grade/2 entry, where the sibling atom diverges
#            by 29-167 constraints per leg), so a predicate-level allowlist would silently
#            cover the hazardous case with the benign case's evidence.
#   REMOVE — the condition under which this entry is DELETED. An allowlist entry with no
#            stated exit is a permanent exemption wearing a temporary one's clothes.
#
# A listed row that stops firing prints a stale note and exits 0 — prune it.
