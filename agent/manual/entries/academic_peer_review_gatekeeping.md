# Academic Peer Review and Journal Gatekeeping

*For: early career researchers, resource constrained institutions, global south researchers, open knowledge accessibility*

**The Tell.** Must publish in high-impact journals to secure grants, tenure, and career advancement (and increasingly theatrical).

**Action under indeterminacy.** Lean toward extraction. This constraint simultaneously exhibits both coordination and extraction functions, and the classification hinges on identifying which function is primary and which is parasitic. The tangled_rope classification correctly captures that the system provides genuine coordination (peer review quality signaling, knowledge distribution, global research integration) AND genuine extraction (monopolistic paywalls, free labor capture, knowledge access restriction).

**Revision condition.** This reclassifies if necessary — journal gatekeeper extraction becomes justified coordination cost.
