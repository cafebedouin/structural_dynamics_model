# The Infinite Prisoner's Dilemma Stalemate

*For: all agents, collective welfare*

**The Tell.** Each agent rationally defects because unilateral cooperation yields the worst payoff (sucker's payoff).

**Action under indeterminacy.** Assume extraction until shown otherwise. The mandatrophy resolution: mutual defection is NOT pure extraction (Snare) when viewed from the institutional level where payoff structures are chosen. It IS pure extraction when viewed from individual agents trapped in an exogenous payoff structure.
