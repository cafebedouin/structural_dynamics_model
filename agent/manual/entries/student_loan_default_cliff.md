# Student Loan Default Cliff

*For: low income borrowers, borrowers with dependent care, borrowers in high cost regions*

**Action under indeterminacy.** Lean toward extraction. This constraint resolves mandatrophy by clarifying that the Tangled Rope classification (not pure Snare) is correct at the system level, but Snare is correct for the low-income subpopulation specifically.

**Revision condition.** This reclassifies if sufficient — cliff is negotiable through plan access (Tangled Rope for middle-income).
