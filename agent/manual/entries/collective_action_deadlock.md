# The Infinite Deliberation Loop

*For: collective action capacity, threat responsive groups*

**The Tell.** The group as a whole experiences total extraction of decision-making capacity (and increasingly theatrical).

**Action under indeterminacy.** Lean toward extraction. The Infinite Deliberation Loop resolves the mandatrophy by exposing how a coordination mechanism (minority protection) can be weaponized into an extraction mechanism (immobility). The rule satisfies both definitions: it genuinely enables coordination for minority protection (Rope function) AND it systematically extracts collective action capacity from the majority (Snare function).

**Revision condition.** This reclassifies if unified bloc — veto power is stable, extraction is systematic, constraint is durable Snare/Tangled Rope.
