# Algorithmic Oversight Erosion

*For: domain experts, judgment capacity*

**The Tell.** Professional judgment is systematically subordinated to automated decision gates that cannot be overridden without creating liability exposure or professional repercussions (and increasingly theatrical).

**Action under indeterminacy.** Lean toward extraction. Mandatrophy Resolution: This constraint exhibits incipient mandatrophy. As edge cases accumulate (omega: edge_case_accumulation), algorithms require growing expert judgment to handle misalignment. But institutional structures prevent expert judgment deployment. The system begins to degrade: audit infrastructure must field exceptions, regulatory bodies face pressure to permit override, operators face liability for algorithmic failures they cannot prevent.

**Revision condition.** This reclassifies if primarily technical — entrenchment is deeper and sunset slower.
