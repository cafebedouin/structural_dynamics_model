# The Cobra Effect (Perverse Bounty Incentive)

*For: public resource allocation, legitimate problem solvers*

**The Tell.** The bounty program's budget becomes diverted to fabricated claims rather than solving the stated problem (and increasingly theatrical).

**Action under indeterminacy.** Lean toward extraction. The cobra effect resolves the mandatrophy between 'This is pure coordination' and 'This is pure extraction' by being both. From the beneficiary perspective, it is pure coordination — a clear rule that coordinates multiple agents. From the victim perspective, it is pure extraction — the rule extracts value from legitimate problem-solvers and public resources.

**Revision condition.** This reclassifies if verification cost < 20% of bounty pool.
