*For: system actual objectives, unincentivized agents*

**Action under indeterminacy.** Hold both possibilities. This constraint resolves the mandatrophy by distinguishing coordination from extraction via temporal evolution and agent position. Early-stage incentive systems (first 1-2 years) function primarily as Rope — metrics closely track true objectives, gaming is minimal, and agents experience the constraint as helpful alignment.

**Revision condition.** This reclassifies if objectives are specifiable — metric designers can construct better proxies, moving toward pure Rope.
