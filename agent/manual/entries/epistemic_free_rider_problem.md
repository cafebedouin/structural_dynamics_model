# The Truth-Mining Exhaustion

*For: primary researchers, epistemic commons, downstream knowledge consumers*

**The Tell.** Original researchers (scientists, journalists, domain experts) bear the full cost of producing ground-truth: laboratory work, field investigation, peer review cycles, verification, and correction (and increasingly theatrical).

**Action under indeterminacy.** Lean toward extraction. The constraint resolves mandatrophy by showing that tangled rope is structurally justified: the epistemic commons DOES receive coordination benefit (derivative information is distributed frictionlessly), AND there IS asymmetric extraction (costs concentrate on researchers while benefits accrue to platforms). Both functions coexist in the same mechanism.

**Revision condition.** This reclassifies if ratio < 10:1, alternative funding models become viable and the snare weakens.
