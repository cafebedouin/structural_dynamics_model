### B. The Four Canonical Observers

DR theory indexes classifications by observer context, defined along four dimensions:
- **Agent power**: powerless → moderate → institutional → analytical
- **Time horizon**: immediate → biographical → generational → civilizational  
- **Exit options**: trapped → constrained → arbitrage → analytical
- **Spatial scope**: local → regional → national → continental → global

The engine computes types for each observer position independently, then checks for thermodynamic consistency (Boltzmann compliance) and perspectival coherence (sheaf gluing). When observers disagree, the engine generates H¹ (first Čech cohomology) as a measure of perspectival fracture—how many discrete classification blocs exist that cannot be smoothly deformed into each other.

**Critical invariant**: When the constraint story declares one type but the engine computes a different type from any canonical observer position, the engine is correct and the story has flinched. This is not a disagreement to be resolved through interpretation—it is a structural finding about what the metrics actually specify.
