# K1 — Kernel-Gate Replication Probe: a real, topic-classed boundary band; gate noise localized to the binary decision

**Date:** 2026-06-05. **Question (gates Stage-2 / OQ-75):** the SCOPE kernel/flat gate routed the
same contested substrate onto different axes in two runs (T5 of
`audits/2026-06-05_scope_count_distribution/`). Is the miss-rate a thin boundary band (stratify
and proceed) or broad stochasticity (structural fix first)? **K3 (hand-adjudication, free,
done first):** gig-economy classification passes all three §1.3-K criteria — the flat take was a
gate MISS against explicit criteria, execution noise, not definitional ambiguity.

**Pre-registered (driver docstring, before any call):** k=8 per topic, current prompt, temp 0.2.
**Invalidation conditions, not calibration:** C-HIGH (personhood, uncontroversial kernel) below
7/8 INVALIDATES the thin-band diagnosis (gate would be noisy on clear kernels too — different

## Findings

1. **The boundary band is real and topic-classed — and within it, the gate is near coin-flip.**
   Famous moral kernels (personhood 8/8, affirmative action 8/8) are stable; statutory/regulatory
   contests (gig classification 5/8, content moderation 3/8) flip. Hypothesis consistent with the
   data: the gate's sensitivity tracks the contest's cultural salience, not the §1.3-K criteria
   (testable by K2's phrasing perturbations — now licensed, since the band is worth diagnosing).
2. **Both band topics are under-firing misses, not boundary ambiguity.** Hand-adjudication
   against §1.3-K: X1 (employee/contractor/hybrid readings — different victim sets) and X3
   (state_action_boundary kernel: formalist / entanglement / public_function readings — mutually
   exclusive groundings) both pass all three conditions. The criteria are clear; the
   single-sample in-passing decision under-applies them.
3. **The noise is localized to the binary gate.** Conditional on firing, reading counts are
   perfectly stable (X1 always 4, X2 always 3, X3 always 3, across runs). Decomposition
   downstream of the gate is reliable; only recognize-or-not flips.
4. **Miss direction is the unrecoverable one.** A flat take destroys the axiom axis (no readings,
   no groundings to diff); a kernel take still carries observer perspectives inside each reading.
   All observed misses are in the destructive direction.

## Stage-2 consequence (OQ-75) and dispositions (recorded, not built — OQ-76)

The cross-axis invariance correlation would, for band-class topics, partly measure this
coin-flip: the same constraint's contestation lands on the axiom axis or the observer axis per
run. Stage-2 must treat kernel-routing as an explicit stratum, or apply the interim hedge first.

- **Interim hedge (one line, operator-ruled when Stage-2 goes):** bias the gate toward kernel on
  boundary-band topics — the error is recoverable in that direction and unrecoverable in the
  other (same defense-in-depth asymmetry as the de-leak: fail toward the recoverable side).
- **Candidate real fix (filed, not built):** generate BOTH representations for band topics.
  Kernel-vs-flat is itself an apparatus perturbation (`the_perturbation_principle.md` §7.1) — the
  diff between the two constructions of one topic is signal, not waste; pre-kernel corpora
  effectively carried flat constructions of later-kernel topics. Scope: forced-flat decomposition
  mode is new code; separate work item with its own ruling.
- **K2 (phrasing-sensitivity probe) is now licensed** as the cause-diagnosis input to choosing
  between gate-hardening (criteria-pinned screening call + k-vote) and generate-both.
