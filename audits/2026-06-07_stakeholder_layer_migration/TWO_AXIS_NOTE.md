## Consequence for the corpus-scale run (Claude web's actionable point, sharpened)

Claude web is right that a corpus-scale run on the **observer** axis is NOT measuring C-vs-B — it
measures how often the two surfaces author different structure (metrics, victim-enumeration) from
one topic, a **generation-resolution** question. Do not let that run inherit the C/B label; C/B
was answered for the observer axis (foreclosed) by architecture, witnessed here.

The genuine two-axis C-vs-B / detection-independence question lives on the **committer axis** and
is a DIFFERENT experiment: vary the committer structure (axioms / grounding / drift), hold the
observer axis, and measure where foreclosure/closure diverges from observer-coherence (Theorem 7).
The stakeholder migration neither created nor tested committer-axis effects; that experiment is
unstarted and is the one that would actually carry the C/B label.
