New standing checker `python/audit_citation_status.py` (sibling of `issues_status.py` /
`known_state_status.py`). The fresh-clone invariant: a path cited from an audit `.md`
must **exist AND be git-tracked, OR be allowlisted-ephemeral**. Missing and
untracked-not-allowlisted are the same violation class; WARN stages by *why* a path is
not yet an ERROR — three sublabels, three destinies.

**Per-path disposition (operator-ruled 2026-06-18 — "leave flagged, defer promotion"):**
Reading every citation context (saved inline below / in git history of the cited audits),
all 35 are **descriptive references to canonical, regenerable `outputs/` artifacts** —
pipeline I/O schema docs (the 2026-02-23 `report_generator` audit: "`outputs/corpus_data.json`

CLI defaults ("default: `outputs/false_mountain_report.md`"), command illustrations
("`cp outputs/pipeline_output.json /tmp/pre.json`"), and one that self-annotates
"(main tree; outputs/ gitignored)". **None is the dangerous OQ-104 origin class** (a unique
frozen result a fresh clone needs and lacks) — those origin cases (spectral_laplacian's 25
evidence files, `tripwire_fabricated_defaults_results.json`) were already remediated at the
2026-06-11 anchor `09390f0f`.

- Disposition **(i) copy-into-audit-dir is inapplicable**: `outputs/` is regenerated by
  every `run_pipeline`, so today's file ≠ the historical snapshot — copying would be a
  Pattern-3 faith-merge (assert current == historical without proof).
- Disposition **(ii) allowlist is forbidden**: gitignored-inside-repo IS the OQ-104
  signature; allowlisting it would re-bury the very thing the checker exists to surface.
- **Operator ruling (2026-06-18):** leave the 35 as `WARN[untracked-pending]` — correctly
  flagged, **non-gating**. `--promote-untracked` stays un-triggered (the set is non-empty by
  design). No historical audits churned. The checker honestly surfaces every gitignored-output
  reference for periodic review; whether descriptive-references-to-canonical-outputs should
  ever gate is deferred to a future ruling.

## Controls (mandatory before done) — all pass

`controls.py` → **23/23** (`controls_out.txt`); `controls_run.sh` → idempotence +
rot-sensitivity (`controls_run_out.txt`). One positive control per new exclusion, plus:

- **en-dash / hyphen / comma-list / symbol anchors** strip and SURVIVE to the tracked file.
- **glob-star** `testsets/*.pl` → grammar-ambiguous (pattern, no crash).
- **brace** `prolog/arakelov_height.{pl,json}` EXPANDS to two members, each checked — `.pl`
  tracked, `.json` flagged (false-negative guard).
- **writeup-relative**: a fixture under `evidence/` (existing-but-untracked in this audit dir)
  resolves writeup-relative and lands in `untracked-pending`, NOT pass-on-existence. (Named
  without a literal backtick path here so this very writeup doesn't self-inflate the count.)
- **home-dir / `/tmp` / absolute-outside-repo** → allowlist; **absolute-inside-repo**
  `<REPO>/outputs/pipeline_output.json` → normalizes to `outputs/pipeline_output.json` and
  is FLAGGED (the pt-G boundary).
- **arity / `mod:pred/N` / field-list / `[…]`-template** drop (not citations).
- **idempotence**: two consecutive runs byte-identical (stdout+stderr).
- **rot-sensitivity** (the standing-checker rationale): a tracked cited file PASSES; the same
  file `git rm --cached`'d (still on disk) FLIPS to `untracked-pending`. A checker
  byte-identical because it *stopped looking* fails this — stability without sensitivity
  proves the wrong half.

A real bug the controls caught: `/etc/passwd` (no extension) was mis-dropped by the
field-list exclusion before the absolute-path branch; fixed by guarding field-list against
leading `/` and `~`.

## Surfaced seat (encoded as default, flagged for override)

Brace `trap.{json,pl}` = **expands-and-checks each member** (a clone could lack `trap.pl`);
glob-star `*.pl` = **illustrative / dir-has-match**, not a hard per-file citation. This is the
"is this a citation" axis the tool turns on. Second seat surfaced + ruled this session:
descriptive references to canonical regenerable `outputs/` artifacts → flagged-but-non-gating
(operator, 2026-06-18).
