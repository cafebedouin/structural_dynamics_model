# A4 — the ratchet test re-run on row A after marking

**Executed:** 2026-08-20, after the A3 marking landed.

§7.8's one-sentence test: *describe the event in which the falsifying branch fires, and name who
observes it* — if the answer is "someone notices incidentally," it is a disclaimer, not a falsifier.

## Before this pass

§14 records: *"RQ2's stated falsifier is therefore now carried by that limb and by §6.2's row **A**
alone."* Row A was unmarked, carried as open residue, and had:

- **no observable** — *no member* is a standing negative; nothing happens when it stops being true;
- **no named observer** — nobody was standing anywhere in particular to notice.

That is §7.8's ratchet exactly, applied to the row carrying a live kill condition: evidence could
only ever accumulate on the keep side.

## After

**The event.** The falsifying branch fires when a member of this taxonomy is shown to index on
*environment* rather than on *layer* — i.e. when §5.1's table gains a member (or an existing member
is re-read as) ranging over where the code is running rather than over a stage of the value's
journey. Because the enumeration restated the zero as an **axis** claim rather than a
**shape-inventory** claim, the branch now has a determinate observable: an eight-row table, one
column, re-readable in a minute.

**The observer.** Whoever next walks §5.1's table against an external environment-indexed class,
standing at the Appendix B `6.2` pointer row — which is where a reader auditing this paper's
witnessed claims stands, and is the read-site §7.8 prescribes for an undated trigger.

**Verdict: no longer a ratchet.** The keep and retire branches are now asymmetric in evidence cost
but symmetric in observability. This is the *undated-trigger* repair of §7.8's three, not the
gate-enforcement one — the trigger has no date, so a sunset check would have nothing to fire on.

## §14 re-read: does it still hold?

**Yes, and it is strengthened.** §14's clause is *"the one defect shape Wu expresses and this
taxonomy cannot."* The enumeration confirms *cannot* in the strong sense — not "happens to have no
member" but "cannot, because the index sets range over different variables." §14 needs no edit.

**One thing §14 would now say differently if rewritten, and is deliberately left alone:** the
enumeration also shows the institution *has* the incidents, which is a fact about §6.2's stated
reason, not about §14's clause. §14 speaks about the taxonomy; the correction that landed is at
§6.2, where the false clause is. Editing §14 would spread a correction to a site that is not wrong —
the ruling-lands-at-one-site failure §14 itself records against the RQ2 retirement, run in reverse.
