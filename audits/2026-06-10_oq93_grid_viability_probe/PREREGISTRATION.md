Whether the three grid consumers, given real (authored, varying) 32-point grids for the first
time in their existence, produce the outputs they were built for. All constants verified
against `config.pl` THIS session (the exploration agent's weight table contained an internal
contradiction — weights re-read from source):

- `aggregation_weights` per level (A,S,U,R): structural (.30,.20,.20,.20) **sum .90**;
  organizational (.30,.40,.15,.15) sum 1.00; class (.30,.20,.30,.30) **sum 1.10**;
  individual (.25,.25,.25,.25) sum 1.00.
- `influence_weight`: structural .40, organizational .30, class .20, individual .10.
- `system_gradient_threshold` = 0.01; `system_gradient_strong_threshold` = 1.00 (strict >);
  `data_high_threshold` = 0.95.

**Pre-registered arithmetic fact (range-death of the top intent verdict):** with all 32 points
authored on [0,1], max G_sys = Σ influence×Δκ_max = .40×.90 + .30×1.00 + .20×1.10 + .10×1.00
= **0.98 < 1.00**, and Condition 1 requires G_sys **> 1.00 strict**. `structural_coercive_intent`
is unreachable on the metric domain REGARDLESS of authoring — checked by story 5, the maximal
case. (Conditions 2–4 read `intent_*` tables no producer has ever populated; story 5
hand-authors them, the only best-case possible.)

## Pinned criteria + per-criterion positive controls (amendments 1–2)

**C1 — gradient correctness (not just non-flatness).** `system_gradient(ID, 0, G)` must equal
the hand-computed value ±0.001:
| story | expected G_sys |
|---|---|
| rising | +0.588 |
| falling | −0.588 |
| flat_authored | 0.000 |
| divergent | +0.156 (= .40×.54 − .10×.60) |
| intent_max | +0.980 |
Positive controls: rising/falling/divergent are the designed-signal inputs — a 0.0 there is
"construct can't see," distinct from flat. The authored-flat story distinguishes flat-from-data
vs flat-from-blindness via the `[grid diet: authored 32/32 ...]` line.

**C2 — pattern labels.** Expected: rising→`increasing_coercion`, falling→`decreasing_coercion`,
flat→`stable`, divergent→`increasing_coercion`, intent_max→`increasing_coercion`. Full label set
covered. Pre-stated code-derived finding: the construct is sign(G_sys)-thresholding by
construction (`pattern_analysis.pl:25-28`) — the probe witnesses label REACHABILITY; the
"not reducible to trivial monotones" criterion is resolved analytically (it IS a trivial
monotone; its distinction capacity is 3 labels from one scalar).

**C3 — intent basin exit + range-death witness.** Stories rising/falling/divergent must exit
the stable basin (verdict = their pattern label, since Conditions 2–4 lack evidence).
`grid_probe_intent_max` is the decisive case: FULL Conditions-2–4 evidence authored + maximal
G_sys=0.98 ⇒ pre-registered verdict `increasing_coercion`, NOT `structural_coercive_intent`
(Condition 1: 0.98 > 1.00 false). If it returns `structural_coercive_intent`, the
range-death arithmetic is wrong — that would be a probe-falsifies-preregistration result,
reported as such.

**C4 — κ display.** `Aggregate Magnitude (Kappa) at Tn` (mean of per-level κ at Tn, 2dp):
rising 0.80, falling 0.20, flat 0.50, divergent 0.49, intent_max 1.00. ±0.005 (display
rounding). Note: class-level κ can exceed 1.0 (weights sum 1.10) — calibration wart, recorded
if visible.

**C5 — honest confidence.** All five: authored completeness 8/8 → DataScore 1.0 ≥ .95 →
Confidence `high` via the fallback path — now an HONEST high (real authored completeness),
vs the corpus's current honest `low` (0/8) and the shim era's manufactured `high`.

shim-off witness), plus a direct `system_gradient/3` query per story for C1 (the report does
not print G_sys numerically).
