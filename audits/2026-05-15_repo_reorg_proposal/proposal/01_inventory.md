## Top-Level Directories

### `prolog/` — 503 MB, 10,889 files — Last commit: 2026-05-15

The Prolog engine and all corpus data. This is the largest directory and contains significant
undocumented subdirectory mass.

**Root-level .pl files (91 total):**
- 1 loader: `stack.pl` — loads 37 modules in dependency order
- 9 generated overlays: `scs_*.pl` — config sensitivity overlays generated by
  `python/structural_config_sensitivity.py`; each does `:- [stack]` then retracts/asserts
  one config param. These are generated artifacts that ended up at prolog/ root rather than
  in a dedicated location.
- 81 named engine modules (see §02_usage_analysis.md for dependency classification)

**README.md/entry point:** `stack.pl` is the loader. No README inside prolog/.

**Module count discrepancy:** The README introduction correctly says "91-module Prolog engine."
The README structure diagram says "[75 additional modules]" alongside 7 named ones (~83 total),
undercounting by about 8. Neither source says 79. The actual count is 91 .pl files, 81 named
modules.

### `sotu/` — 13 MB, 447 files — Last commit: 2026-04-07

SOTU (State of the Union) sub-project workspace. Parallel structure to the main corpus.

**Relationship to `prolog/testsets_sotu/`:** The `sotu/pl/` directory (189 files) contains files
with **identical content** to `prolog/testsets_sotu/` (189 files) — verified by diff on a
representative file. The sotu/ directory is the authoring workspace; prolog/testsets_sotu/ is
where the engine loads from. The duplication appears intentional but is undocumented.

**Structure:**
- `raw/` (65 files) — original SOTU speech texts (source data)
- `json/` (189 files) — generated constraint JSON for each SOTU constraint
- `pl/` (189 files) — Prolog testsets, identical to prolog/testsets_sotu/
- `sotu_manifest.json`, `sotu_seeds.json` (158 KB), `sotu_processed.txt`, `sotu_scope_processed.txt`

**Pipeline reference:** `run_pipeline.py` hardcodes `TESTSETS_SOTU_DIR = PROLOG_DIR / "testsets_sotu"` — the engine reads from prolog/testsets_sotu/, not from sotu/pl/.

**No README inside sotu/.**
